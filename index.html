MOGUL CHALLENGE
ターン
コブが判定ライン（点線）に重なった瞬間に、画面の左右を交互にタップ。 早くても遅くても点が下がる。連打しても点にはならない。
エア
エア台の手前の緑の SET ラインでタップして構えを作る（セット）。 空中でもう1回タップして着地を合わせる。
空中のボーナス
飛んだ直後に技の名前が出ている間にタップすると成立する。 そのあと、いつも通り着地のタップをする。押さなくてもよい。
グラブ（板をつかむ）…バックスクラッチャーはセーフティ（同じ側の板の後ろ）、 360・コーク720 はミュート（体をまたいで反対側の板の前）。どれも DD が上がる。
ダブル（技が発展する）…アイアンクロスはこちら。タップするとコザックへ変わり、 1本のエアで技を2つ続けたことになる。DD は 0.41 → 0.55。
ホールド（形を保つ）…バックフルはこちら。グラブではないので 空中の姿勢は変わらず、DD も上がらない。上がるのは技の完成度（評価点）だけ。
スプレッドは両腕を開くことが技なので何もできない。
技えらび
緑のボタン（SPREAD / BACK SCR / IRON X）は回らない技。 着地を合わせやすいかわりに DD が低い。青のボタンは回る技で DD が高い。
バランス
ターンを外すと BALANCE が減り、尽きると転ぶ。転ぶと立て直すまで数ターンかかる。
採点
スタート画面の HELP でいつでも読めます
